# Publish to GitHub

Target repository: `kamoyum/intelligence-os`

## Recommended first publication

Create a **public** GitHub repository named `intelligence-os` with:

- no autogenerated README (this repository already contains one)
- no autogenerated `.gitignore`
- no autogenerated license yet
- default branch: `main`

Recommended description:

> Experimental local-first Personal Cognitive Infrastructure: memory, verification, outcome learning, bounded automation, and safety-limited AI authority. Developer Alpha.

Recommended topics:

`ai`, `local-first`, `human-ai-collaboration`, `context-engineering`, `evals`, `ai-safety`, `personal-ai`, `verification`, `agentic-systems`

## First push from a computer

From the extracted `intelligence-os` folder:

```bash
git init -b main
git add .
git commit -m "Initial public Developer Alpha release: v0.7.2-alpha"
git remote add origin https://github.com/kamoyum/intelligence-os.git
git push -u origin main
```

Then open GitHub Actions and confirm:

- CI passes
- CodeQL completes
- Dependabot is active

## Before announcing publicly

1. Enable **Private Vulnerability Reporting** if available.
2. Confirm `SECURITY.md` is detected by GitHub.
3. Confirm there are no secret-scanning alerts.
4. Run or confirm CI on `main`.
5. Create GitHub Release `v0.7.2-alpha` and mark it **Pre-release**.
6. Attach the generated `intelligence-os-v0.7.2-alpha.zip` if desired.
7. Paste `RELEASE_NOTES_v0.7.2-alpha.md` into the release notes.
8. Link `KNOWN_LIMITATIONS.md` prominently.
