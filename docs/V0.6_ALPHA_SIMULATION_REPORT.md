# v0.6-alpha Simulation Report

Outcome Learning was tested at both function and HTTP levels with synthetic data.

PASS conditions:
- expectation persisted;
- decision linked to expectation;
- outcome linked to expectation/decision;
- prediction mismatch calculated;
- no learning Memory created before human acceptance;
- reflection created a proposed lesson;
- accepted lesson promoted to private local Memory;
- expectation lifecycle closed as `learned`;
- rejected lesson does not create Memory.

The simulation validates the control flow, not causal inference or statistical forecast validity.
