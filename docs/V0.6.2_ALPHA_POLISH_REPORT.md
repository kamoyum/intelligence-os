# Intelligence OS v0.6.2-alpha — Polish / Hardening Report

## Why this release exists
v0.6.1-alpha was functional but several capabilities were borderline: deterministic Executive routing, non-goal-aware Attention, query privacy gaps, passive Outcome follow-up, coarse source metadata, and release reproducibility.

## Changes
1. **Executive task profile** now includes evidence requirement, Query Safety, and explicit human checkpoint.
2. **Query Safety** detects common secrets/credentials and PII-like/sensitive context. Secret queries cannot be sent to Web Research even when explicit permission is supplied.
3. The same Query Safety policy now gates **external reasoning, LLM eval, LLM verification, and embedding query transmission**.
4. **Goal-aware Attention** ranks Memory using human goal relevance + importance + recency.
5. **Outcome due follow-up** surfaces overdue/upcoming Expectations in Brief.
6. Research authority is split into government/regulator, original research, vendor-primary, academic, organization, public-web priors.
7. Vendor-primary evidence is capped for normative/comparative claims; a vendor is not automatically a strong authority on “best/safest/recommended”.
8. Common HTML publication metadata and PDF metadata are captured when available; unknown date remains unknown.
9. Skills expose maturity/executor metadata so prompt contracts are not presented as fully executable machinery.
10. Preflight checks Python/dependencies/data-dir/pip consistency before Desktop launch.
11. Release builder runs compile + tests + simulations + benchmark + archive hygiene checks.
12. Kernel benchmark currently fixes 8 Executive and 6 Verification representative cases.

## Verification performed in this release

## Still not proven
- live OpenAI Web Search/reasoning/eval/embedding E2E in this environment
- live Google OAuth sync
- real Chrome GUI/macOS/Windows signed installer E2E
- production-grade network sandbox / encryption-at-rest

## Product interpretation
This release improves the Kernel without increasing autonomous authority. It intentionally moves Intelligence OS toward **reliable cognitive infrastructure**, not toward “more agents for their own sake”.
